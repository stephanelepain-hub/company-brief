# Company brief

Work in progress.

One web page that helps a small business write a single brief about itself (who you are, what you offer, prices, tone, standard terms, what must never be shared) and gives you a ready-to-paste version for the AI assistant you use.

- One HTML file. Open it in a browser. No install, no account, no API key.
- Nothing you type leaves your browser.
- MIT licence: any company can use, change and reuse the code.

Status: early mock-up. Download `index.html` and open it in your browser.
